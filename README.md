# Lucy

Lucy is a small, single player virtual world prototype. Wander the map, visit the glowing landmarks, and read their stories. Your position is saved locally in your browser.

## Run

Requires Node.js 18 or newer. No packages or external services are needed.

```sh
npm start
```

Open `http://localhost:3000`. Use the arrow keys, WASD, or the on screen controls. Set `PORT` to choose a different port.

## Check

```sh
npm test
```

The first version is a local prototype. Shared multiplayer worlds and accounts are future features.
