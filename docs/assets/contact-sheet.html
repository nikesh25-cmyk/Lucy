The family

id nemoworld-commons · spec 1.0.0-spec · 51 entries · 45 produced · 2 vendored third party · 4 specified, nothing produced

One coherent family: original project-authored, flat-shaded cube geometry, plus the two third-party art sets already vendored in this repository that the existing code paths can already address (the CC0 mayor sprite sheets and the ISC Lucide icon set). No third-party 3D mesh pack is selected, and nothing is downloaded, imported or integrated by this task.

Grid contract, in the project's own units

Tile
1 tile = 1 virtual metre. The shared frontier is 16 x 16 areas of 48 x 48 virtual metres, in 8 x 8 parcels of 6 x 6 (docs/VOXEL_WORLD.md, docs/LAND_WORLD.md).
Block
Blocks are 1 x 1 x 1 m cubes on integer layers z 0 to 7 (content/README.md stack.z_min/z_max; VOXEL_LIMITS.height = 8).
Axes
world X = tile x, world Z = tile y, world Y = block layer z (src/voxel-world.js cubeBatch). A pick keeps horizontal x/y and vertical z.
Resident
1.52 m tall, 0.38 m half-width; ground detail ≤ 0.10 m; knee height 0.50 m
Classes
occupies its tile at resident height; not walkable; roofs and canopies rise above 1.52 m; flat ground detail at or below 0.5 m inside its own tile; walkable; frame open marker; geometry in the tile-edge bands with cross members above 1.52 m; walkable

Why this family and not a licensed mesh pack

  1. The pinned renderer has no model loader. Importing assets/vendor/three-voxel.js exposes exactly 27 symbols (ACESFilmicToneMapping, BoxGeometry, CanvasTexture, Color, DirectionalLight, EdgesGeometry, Fog, Group, HemisphereLight, InstancedMesh, LineBasicMaterial, LineSegments, Matrix4, Mesh, MeshBasicMaterial, MeshLambertMaterial, Object3D, PCFShadowMap, PerspectiveCamera, Raycaster, SRGBColorSpace, Scene, Sprite, SpriteMaterial, Vector2, Vector3, WebGLRenderer) with no GLTFLoader, no OBJLoader and no TextureLoader. Measured 2026-10-13; the file is 551,333 bytes with SHA-256 37fe9184bb0c982e1d48e77375fbeb6b2f8a3fdd54b62a5f0cd87499fdcb5e88, the same values assets/vendor/three-source-manifest.json records.
  2. No licensed pack is a drop-in. Every 3D candidate in docs/research/ASSET_SHORTLIST.json records integration_cost "High" for the same missing-loader reason, and none is grid-aligned: Kenney Nature Kit (CC0, 10.05 MiB, 330 organic low-poly models), Kenney City Kit Suburban (CC0, 2.90 MiB, modern suburban vocabulary), Kenney Furniture Kit (CC0, 4.89 MiB), KayKit Adventurers (CC0, rigged humanoids with skeletal animation) and KayKit Medieval Hexagon (hex tiles on a square grid).
  3. Re-bundling the renderer was already rejected. docs/VOXEL_WORLD.md records the bundle as pinned and hash-verified; docs/research/ASSET_SHORTLIST.md "What a selection would still require" states that adding a loader means re-bundling and re-hashing, which the engine decision record (docs/VOXEL_ENGINE_REUSE.md) rejected for meshing. That is an engineering decision, and no asset download settles it.
  4. Per-file terms inside every pack archive are still unread. docs/research/ASSET_SHORTLIST.json unresolved_rights_register says the licence was read from the publisher's own repository file or asset page, but the License.txt inside each archive was not inspected, because that would require a download this task forbids. No pack can be called fully verified today.
  5. The content layer already answers the same question this way. content/THIRD_PARTY.md records every block, furniture, crop and cosmetic definition as LicenseRef-NemoWorld-Project-Authored with appearance.geometry "cube" or a builder name in src/voxel-world.js, and the 20 appearances as the only third-party art. This library extends that answer rather than contradicting it.
  6. The two vendored sets work through paths that exist now. Lucide SVGs are served as files and used through <img> plus a CSS filter (server.js:71, app.js:507, nemo-theme.css:11); the CC0 mayor sheets load through the 2D canvas atlas route and are sealed as content/appearances/*.json. Neither needs a new loader, a CSP change or a new dependency.
