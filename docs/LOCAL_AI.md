# Project-local AI on Apple Silicon

Open **Enable Local AI.command** after the Mac launcher has installed Node. The installer downloads the official llama.cpp `b11429` Apple Silicon runtime and Qwen3-4B Q4_K_M weights into this project's `.runtime/ai/` directory. Model download size is 2,497,280,256 bytes. Allow at least 5 GB of free disk space for download and installation. No cloud provider account is required.

The runtime is MIT licensed and includes its licence. The official [Qwen model repository](https://huggingface.co/Qwen/Qwen3-4B-GGUF) declares Apache 2.0. We pin model commit `bc640142c66e1fdd12af0bd68f40445458f3869b` and verify its LFS SHA256 `7485fe6f11af29433bc51cab58009521f205840f5b4ae3a32fa7f92e8534fdf5`. The [runtime release](https://github.com/ggml-org/llama.cpp/releases/tag/b11429) archive SHA256 is `740288ec6887be94280a5dfa25b5e23a78285cab104519e6c7e218904ee82459`. Interrupted curl downloads retain bytes and resume on the next installer run. A checksum mismatch never enables inference; remove the named corrupt download before retrying.

After successful installation, **Start World.command** verifies the weights, executable and library receipt, starts the model on a dynamically selected loopback port, waits for readiness, and starts the world with that private endpoint. It uses one inference slot, an 8,192-token context, four CPU threads, Metal acceleration and an ephemeral API key passed through the child process environment. It disables the model web UI. Closing the launcher stops both servers. To explore without inference, launch with `LUCY_LOCAL_AI=0`.

Existing `LUCY_MODEL_NAME` configuration takes priority over automatic startup. The default adapter remains Ollama; choose `LUCY_MODEL_BACKEND=llama.cpp` to use a separately managed local llama server, with `LUCY_MODEL_URL`, `LUCY_MODEL_NAME`, and optionally `LUCY_MODEL_KEY` in a private environment. Both adapters reject remote endpoints and redirects. Keys, binaries, weights and databases are excluded from Git.

Mayors return provisional conversational guidance. Research workers return provisional source-grounded briefs with an evidence register. Model output is never independent review, a government decision or proof of an outcome. Invalid or timed-out mayor responses fall back to scripted guidance. A failed research synthesis releases its claim when its credential remains usable; it does not silently submit fabricated work.

Installation and generation are distinct verification steps. The local installation can be incomplete while the world remains usable. Runtime executable verification does not establish model quality. Test a real bounded mayor conversation and a primary-source research submission after weights finish downloading, and keep the independent review stage.
