# NemoEarth design for Lucy

Lucy now applies the design language observed in the existing NemoEarth public build and source. Deep forest backgrounds, ivory Cormorant headings, Manrope controls, subdued gold, translucent panels and fine borders replace the light interface. Lucy keeps its own identity, source records and authority boundaries.

The shell, home entry, navigation, cards, forms, account dialog, research workflow, evidence tables, review/governance screens, passport and coin wallet share the new stylesheet. The desktop sidebar can scroll when authenticated roles add more navigation. Core mobile pages fit at 390 pixels.

## Maps

The country atlas now uses a deep ocean, muted graticule, natural land tones, fine coastlines and gold selection. Coverage colours still mean retained agriculture series, not country performance. All 248 entries remain available through the native selector; the 175 outline coverage limit and source qualifications stay visible. Projection and geometry are unchanged. The pixel world receives coordinated framing, captions, controls and toned artwork. This release does not claim a new three-dimensional globe, new terrain geometry or photorealistic assets.

## Fonts and provenance

Manrope and Cormorant files came from NemoEarth's public assets, with its supplied SIL Open Font License 1.1 notice. Local font routes avoid third-party requests. Original bytes and SHA256 are recorded in nemoearth-font-source-verification.json. The font notice is included as assets/fonts/nemo-FONT-LICENSE.txt. No NemoEarth private workspace data, credentials, trademark logo, photographs or videos were copied.

Source reference: existing NemoEarth completion checkout, inspected 12 October 2026. Its local public build rendered the forest, ivory and gold direction. The public nemoearth.si domain could not be read by the web tool; local source and rendered build were used. The reference capture is nemoearth-design-reference.png.

## Verification

All 220 existing platform tests passed after the stylesheet/font routes were added. Browser QA verified loaded font families, country selection and private coin receipts. Desktop navigation covered public exploration, country/assembly/research, community/missions/gallery, Guide, wallet, Review, Mission studio, Safety and Administration. At 390 pixels, wallet, passport, character management, assembly, research, country atlas and mission studio matched the viewport width without page overflow. Administrator Guide opened the review queue. Sign-in and keyboard sign-out worked; temporary viewport and fixture tabs were cleaned up.

These checks cover the observed interfaces and existing functional suite. They are not an independent full accessibility certification or broad user acceptance study. Research, coin and world permissions are unchanged by this stylesheet.
