The Quiet Survey

A practice quest with Lyra. It is practice only and awards nothing. Each step is shown only once the game server has observed it.

    Enter your code

    1. In Veloren, say to Lyra: link my account. You can also send it privately with /tell Lyra link my account.
    2. Lyra answers in a private message with a code. It works once and lasts 10 minutes.
    3. Type that code below.

    Ten characters, for example ABCDE-FGHJK. Only enter a code you asked for yourself, in your own game. Never share it.
